# Demo reference samples

Place curated example photos in the matching category folder (`.jpg`, `.jpeg`, `.png`, or `.webp`).
These files are prototype comparison references, not a trained model dataset. Keep source and licence
notes with any samples added for a demo.

The repository currently has no road or road-defect photos. The empty folders are intentional: until
real samples are supplied, the endpoint returns `REVIEW_REQUIRED` and the app blocks report submission.
Do not put application icons or synthetic placeholders here and treat them as road evidence.
